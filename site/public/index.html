Keep many agents in flight

Agent Manager handles setup, tracking and state, so you only step in where you're needed.

🌿

Worktree per agent

Give a git URL or a folder. Each agent gets its own worktree and branch. Partial clones keep big repos fast.

🖥️

Background terminals

Agents run in the daemon's PTYs. Open a live terminal in the browser or attach from your shell, then walk away.

🔁

Sessions that resume

Every agent keeps its session IDs. Close it, reboot, come back: claude --resume picks up where it left off.

📋

A brief for each agent

Problem, solution, a Mermaid flow diagram and checks, plus PRs, bugs, diff stats, tokens and cost.

📥

Backlog

Queue work orders. Agents pick them up one at a time, up to N in parallel per project. You accept or reopen each one.

📱

From your phone

HTTPS on your local network with QR sign-in. Answer Claude's prompts from anywhere in the house. Slack alerts too.

Checksums: SHA256SUMS. The bundles aren't code-signed yet. If you download with a browser on macOS, clear the quarantine flag after unpacking: xattr -dr com.apple.quarantine agentmanager-*. The install script doesn't need this.

Get started

You need the Claude Code CLI and git. gh is optional and enables PR tracking.

1. Install from a download

tar -xzf agentmanager-darwin-arm64.tar.gz
mkdir -p ~/.local/bin
ln -s "$PWD"/agentmanager-*/bin/agentmgr ~/.local/bin/agentmgr

2. Open the UI

agentmgr ui               # http://127.0.0.1:4717
agentmgr service install  # start at login

3. Spawn agents

agentmgr add -r https://github.com/org/repo.git \
  "Fix the flaky login test" \
  "Add CSV export to reports"

4. Check in

agentmgr ls               # status, PRs, checks
agentmgr attach <agent>   # live terminal
agentmgr brief <agent>    # problem / solution / checks
